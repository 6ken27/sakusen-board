# うごく作戦ボード

バスケットボール（5人制・ハーフコート）の戦術シミュレーター。

https://6ken27.github.io/sakusen-board/

## できること

- **作戦集**：ボールスクリーン、オフボール、カット、ポスト、ドライブ、ゾーン攻略の28戦術。やりたいことを入力すると合う作戦を探せる
- **再生**：攻めやすい場所を緑の地図で表示し、パスやシュートのねらい目に「ここが空く！」を出す。守備はスクリーンへの対応（ドロップ／ショウ／スイッチ／ブリッツ／アンダー）、ヘルプ、ローテーション、クローズアウトを判断して動く。攻撃はシュート、パス、ドライブ、カット、リフト・ドリフト、再スクリーンを選ぶ。タイムラインで好きな場面に戻せる
- **分析**：同じ作戦を60回試し、期待得点、ノーマーク率、シュートの内訳、スクリーン対応ごとの得点を出す
- **作成**：選手を配置し、コマごとに走る・ドリブル・スクリーン・パスを指で描く。作った作戦をそのまま守備に当てて試せる
- **試合**：5人制のスコアシート（FIBA・JBAの記録方法を参考）。得点、フリースローの本数つきのファウル（相殺・ファイティング・失格GD）、タイムアウト、交代を記録。チームファウル（4つで次からペナルティ）、タイムアウトの残り（4Qラスト2分は2回まで）、退場、ポゼッションの矢印を管理。試合番号・審判・テーブルオフィシャルズ・キャプテン・登録番号を入れ、確定後にA4の記録用紙（署名欄つき）を印刷・PDF化
- **スカウト**：端末内の試合動画を再生しながら、相手の攻撃（形・選手・位置・結果）と守備（守り方・スクリーンへの対応）をタップで記録。傾向をまとめ、相手の守り方に作戦集の作戦を当てて効く作戦を順位づけ。動画は保存も送信もしない
- **マイ作戦**：作った作戦を端末に保存（外部には送信しない）
- ホーム画面に追加すると、オフラインでも使える（PWA）

## ファイル

- `index.html` 画面
- `plays.js` 戦術データ
- `engine.js` シミュレーション（守備・攻撃の判断）
- `app.js` 再生・分析・作戦エディタ
- `game.js` スコアシート
- `scout.js` スカウト
- `sw.js` オフライン用
